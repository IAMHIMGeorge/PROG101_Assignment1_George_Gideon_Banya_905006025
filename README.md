## WASTE REPORT SYSTEM

The **Freetown Community Waste Reporting and Prioritisation System (FCWRPS)** is a proposed programming-logic solution for managing community waste reports in Freetown.

The system allows users to submit information about a waste problem, checks whether the information is valid, assesses its urgency, assigns a priority level, identifies the relevant service area, and tracks the report until it is resolved.

The project focuses on **programming logic and system design**, rather than developing a complete live waste-management application.

## Problem

Waste problems such as uncollected waste, waste near drains, large waste accumulations and potential health or flooding risks need to be reported and organised effectively.

The system provides a structured way to turn these complaints into records that can be prioritised and followed up.

## Objectives

The system is designed to:

- Record waste-related complaints.
- Validate submitted information.
- Assess the urgency of each report.
- Calculate and assign a priority level.
- Identify the relevant service area.
- Track report status.
- Process multiple reports.
- Demonstrate programming logic concepts.

## System Process

```text
Start
  ↓
Enter Waste Report
  ↓
Validate Information
  ↓
Calculate Priority
  ↓
Assign Priority Level
  ↓
Identify Service Area
  ↓
Display Report
  ↓
Update Status
  ↓
Process Another Report?
  ↓
End
```

The system records information such as:

- Report ID
- Location
- Waste type
- Quantity level
- Days waiting
- People affected
- Flood risk
- Health risk
- Priority
- Service area
- Report status

## Priority System

The system uses an **illustrative priority score** based on factors such as flood risk, health risk, waste near drains, people affected, waiting time and waste quantity.

Reports are classified as:

```text
URGENT
HIGH
MEDIUM
LOW
```

The scoring rules are project assumptions used to demonstrate programming logic and are not official municipal policy.

## Report Status

Reports move through the following stages:

```text
Pending → Assigned → In Progress → Resolved
```

## Computational Thinking

The project applies:

- **Decomposition** – breaking waste reporting into smaller tasks.
- **Pattern Recognition** – identifying common characteristics of waste reports.
- **Abstraction** – focusing on information needed to process reports.
- **Algorithmic Thinking** – creating a step-by-step solution.

## Scope

The project is a logical design and does not include a live database, GPS system, payment system, truck scheduling or direct integration with Freetown City Council.

## SDG Alignment

The project primarily supports **SDG 11 – Sustainable Cities and Communities** by improving the organisation and reporting of community waste problems.
